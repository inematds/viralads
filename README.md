# 🎯 Anúncios Virais com IA

Curso completo no formato **INEMA.CLUB** para público de meia-idade para frente:
**encontrar, desconstruir e recriar anúncios que vendem** usando inteligência artificial.

Baseado no método "caçar → estudar → lançar" (não reinvente a roda: copie o que já funciona)
e no uso de UGC (conteúdo de gente comum), que converte ~10x mais que anúncio tradicional.

## 🌐 Site publicado (GitHub Pages)

https://inematds.github.io/viralads/

## Estrutura

- `index.html` — landing page
- **T1 · Fundamentos** (`curso/trilha1/`) — por que UGC vende mais, mentalidade do caçador, ciclo de vida do anúncio
- **T2 · Caçar** (`curso/trilha2/`) — bibliotecas grátis (Meta + TikTok), os 4 sinais de um campeão, lista e download
- **T3 · Desconstruir** (`curso/trilha3/`) — as 5 dimensões, análise quadro a quadro, catalogar padrões
- **T4 · Criar** (`curso/trilha4/`) — o fluxo com IA, ator e voz, realismo/variações/segurança

4 trilhas · 12 módulos · 72 tópicos · linguagem acessível, passo a passo.

## Como abrir localmente

Basta abrir `index.html` no navegador. São páginas HTML estáticas (Tailwind via CDN), sem build.
